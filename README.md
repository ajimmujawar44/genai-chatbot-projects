## Projects

### Simple FastAPI Chatbot Starter

A minimal FastAPI application that provides a foundation for developing chatbot APIs.

- **Technologies:** Python, FastAPI, Uvicorn
- **Project files:** [`simple-fastapi-chatbot-starter/`](simple-fastapi-chatbot-starter/)

### Gemini-Powered GenAI Chatbot

A web-based chatbot with a FastAPI backend powered by Google's Gemini API.

- Gemini API integration and Google Search grounding
- Interactive chat interface with dark and light themes
- India date and time handling
- **Technologies:** Python, FastAPI, Gemini API, HTML, CSS, JavaScript
- **Project files:** [`gemini-powered-genai-chatbot/`](gemini-powered-genai-chatbot/)

## Getting started

1. Clone this repository.
2. Open the project folder you want to run.
3. Follow that project's README for setup and run instructions.
4. Put any required credentials in a local `.env` file. Never commit API keys or other secrets.
